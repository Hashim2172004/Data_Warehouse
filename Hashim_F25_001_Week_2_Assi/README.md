# PakFreight Python assignment

1. Extract the entire ZIP into a folder.
2. Open a terminal there and run `python -m pip install -r requirements.txt`.
3. Run `python -m jupyterlab` and open `PakFreight_Week2_Assignment.ipynb`.
4. Choose **Kernel → Restart Kernel and Run All Cells**. Keep `data/` beside the notebook.

The notebook is already executed, with outputs included. It contains all five written tasks, original architecture diagrams, raw profiling, a repeatable pipeline, exact stovepipe arithmetic, row-level lineage, exclusions, validations and charts. `DWBI_W2_Assignment.md` is the written submission copy. `PakFreight_Activity_Completed.xlsx` is the completed formula-based student activity workbook. Original source files and instructions are included.

For command-line processing run `python pipeline.py`; this recreates CSV/JSON results without editing input files. Student name/roll number were not supplied for this request; enter them before handing in and rename the submissions if required.
